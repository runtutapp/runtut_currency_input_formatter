## 0.1.0 - 2026-05-21

- Initial release
- `CurrencyInputFormatter` — locale-aware currency input formatting for Flutter
- Separators derived from `locale` via `intl`; decimal digits (0 or 2) derived from ISO 4217 `currencyCode`
- Supports IDR, JPY, KRW, VND and other zero-decimal currencies out of the box
